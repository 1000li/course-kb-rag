## 附：tokenizer [UNK] 缺陷闭环 + q23 移出标定（2026-10-08，本节为手工追加，重跑 eval 会被覆盖需补回）

**发现（真实使用暴露）**：部署前 CLI 实测用户真实提问「AI是什么意思？」被双信号与门误拒；进一步诊断发现 bge-small-zh-v1.5 的 tokenizer 把全大写拉丁缩写（AI/AIGC/CNN/GPT/RGB/HSV/NLP…）整体映射为 `[UNK]`——"AI" 与 "AIGC" 的 embedding 余弦相似度高达 **1.0000**（语义全毁），而小写形式分词正常。

**定位与修复**：嵌入侧 `embed_texts` 与 BM25 侧 `tokenize` 均未做大小写归一化，索引与查询同经此二函数对称中招。修复：`src/index.py::embed_texts` 增加 `normalize_text`（`str.lower()`，CJK 不受影响），`src/retrieve.py::tokenize` 同步小写化；索引全量重建（640 向量）。修复后 "AI" vs "AIGC" cos 降至 0.7960，语义区分恢复。另修复标定实现缺陷：tv/tb 中点此前取整落库，tv 中点 0.17415 被截为 0.1741，恰低于边界应拒答题 q23 的 maxVec=0.17413 致其漏拒；现阈值存全精度浮点。
