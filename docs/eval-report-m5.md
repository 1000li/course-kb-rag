## 附二：查询理解层（2026-10-08，第二次真实提问驱动；手工追加，重跑 eval 会被覆盖需补回）

**发现（真实使用暴露）**：用户问「我想知道第一课有什么作业」被拒答（maxVec=0.0064）；问「第1课的思考题是什么」虽过门但 top-1 张冠李戴到第 3 课（该块正文含"第1课"交叉引用字样）。双根因：① 课号是元数据，chunk 正文通常不含自己的课号，BM25 把"第1课"匹配到其他课的交叉引用，向量也不知道 lesson_no；② 词汇 mismatch——讲义用"思考题/课后任务/课后延伸"，从不用口语词"作业"。

**实现（src/retrieve.py 查询理解层，架构 §4 第 8 条 / v0.5）**：
- **课号识别**：`parse_lesson_no` 解析"第N课/第N节课"（中文数字+阿拉伯数字，"第几课"不匹配，多处提及取第一个）；命中则在**召回阶段** scope 到 lesson_no=N（向量 KNN 后过滤取课内前 20；BM25 语料收缩到该课再打分，idf 依赖语料）；课号不存在 → 空 scope → 拒答。
- **同义词扩展**：保守映射表 `SYNONYM_EXPANSIONS`（仅三组：作业→思考题/课后任务/练习；讨论→思考题/讨论；练习题→练习/实践），命中即在 query 尾部追加，嵌入与 BM25 共用扩展后文本。
- **拒答口径配套修订**：课内小语料的 vec/BM25 绝对分值与全库标定的双信号阈值不可比（实测课内正确命中 maxVec≈0.006、maxBM25≈4，若走与门必误拒，且若把课号题放进标定集则"标定方法照旧"不可行——应拒答 maxBM25=9.26 与课内可答题 4-6 的区间重叠过深，calibrate 返回"不可行"）。因此课号 scope 题不走与门：仅空 scope 拒答，有块交 LLM 依据块作答（系统提示词强制只依据块）。qa.should_abstain 与 eval 的 abstained 判定同口径。

**防回归**：eval 追加 q29-q31（课号识别/中文数字+扩展/用户原话三路径），均 `calibration=false`（分值不可比，不参与标定与拒答类指标；recall 仍计入）。本报告 31 题即查询理解层基线：recall@5=100%（25/25）、MRR=0.960、应拒答 5/5、误拒率 4.5%（仅 q27 已知残余），**阈值未变**（tv=0.091300 / tb=9.2569），不带课号的原题行为不变（抽查 q24 正常作答、q19 量子计算正确拒答）。

**CLI 实测**：「我想知道第一课有什么作业」→ L1 课后任务块（课后探索地图三条任务，出处第1课 P5-6）；「第1课的思考题是什么？」→ 出处均第1课；「第五课的讨论问题」→ L5 三道思考题+延伸挑战。
