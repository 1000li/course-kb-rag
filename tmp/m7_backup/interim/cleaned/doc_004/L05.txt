本节课涉及的知识点：
1、机器学习:机器学习需要你不断给AI“喂”数据，让它自己总结规律（比如识别垃圾邮件），
不用逐行写代码。
2、机器学习的类型：
监督学习像老师带学生做题：给AI带‘答案’的练习册（标注数据），让它学会预测结果，
比如根据照片判断猫或狗；
无监督学习像整理杂乱的书架：AI把相似的书自动摆在一起（如客户分群），不需要提
前贴标签;
强化学习像训练游戏高手：AI通过试错学习，赢了得‘奖励’，输了受‘惩罚’，最终掌握下棋
或自动驾驶。
3、深度学习与神经网络：深度学习方法模仿人脑神经元：多层‘筛子’层层过滤数据，最终识
别出图片中的笑脸或文字，在当前的机器学习领域使用很普遍。
4、AI项目开发流程:像做一道菜：收集食材（数据）→清洗（去坏数据）→调味（训练模
型）→品尝改进（测试优化），最终做出AI应用。

一. 什么是机器学习？

想象你是一位小吃店老板，计划推出一款新口味的鸡蛋糕。为了预测销量，你分析
历史数据发现：大份鸡蛋糕比小份多卖出30%，加芝士的款式在周末销量翻倍，阴雨天
气时海苔口味更受欢迎。这个过程与机器学习非常相似。

机器学习就像一门“数据烹饪术”——数据特征如同食材（尺寸、配料、天气），算
法如同菜谱（决策树、神经网络等），损失函数则像试吃反馈，帮助调整配方，最终训
练出的模型就是精心烹制的菜品。通过不断优化，计算机能自动从数据中学习规律，就
像厨师通过试吃改进菜品一样。

1. 机器学习类型探秘

在机器学习的世界里，算法主要分为三大类。

监督学习如同使用带答案的习题册，系统通过标注数据学习规律。例如人脸识别系统需
要大量标注姓名的人物照片进行训练，就像我们通过反复练习数学题掌握解题方法。在
MNIST 手写数字识别任务中，计算机正是通过学习数万张带标签的数字图片，最终能准确

发现隐藏的喜好流派。

2. 深度学习揭秘：神经网络积木

人脑由860 亿神经元构成复杂认知网络，人工神经网络正是受此启发。单层感知
机如同基础积木，只能构建线性决策边界——就像用直尺划分“及格”与“不及格”的分数
区间。但当我们将积木多层堆叠，就能搭建出识别猫狗照片的深度网络。课堂上将通过
代码展示这个过程：

# 神经网络结构可视化示例
import tensorflow as  tf
model = tf.keras.Sequential([
tf.keras.layers.Flatten(input_shape=(28, 28)), # 将28x28像素展平
tf.keras.layers.Dense(128, activation='relu'), # 隐藏层：128个神经元
tf.keras.layers.Dense(10)           # 输出层：10个数字类别
])
这段代码构建的神经网络，能够识别手写数字图像。第一层将784 个像素点展开，
第二层通过激活函数捕捉复杂特征，最终输出 0-9 各类别的得分。有趣的是，美颜滤
镜正是利用类似网络定位五官：当你在照片上添加兔耳特效时，卷积网络正在分析面
部72个关键点。

3. 项目流程认知：AI 工程师闯关

开发一个AI 应用就像完成科学实验一样需要严谨的步骤。首先需要收集数据，这
是AI 的"学习资料"。比如要开发识猫软件，就要收集几千张不同品种猫咪的照片，还要
包含其他动物照片作为对比。这些数据可能来自网络爬虫、传感器或人工拍摄。

接着进行数据清洗，就像整理错题本。需要删除模糊的照片（错误数据）、统一图
片尺寸（格式标准化），还要给每张图打标签，比如在猫咪照片上标注"布偶猫"、"狸花
猫"等分类信息。根据IBM 统计，数据清洗通常占整个项目60%的时间。

然后进入模型训练阶段。程序员会选用现成的AI 框架（如TensorFlow），把处理
好的数据输入计算机。计算机会通过数学算法寻找数据规律，比如发现"有三角形耳朵和肉
垫的特征大概率是猫"。这个过程可能需要高性能电脑运行数小时，期间工程师会监控准确
率，如果发现AI 对练过的照片很准、换新照片就出错（过拟合），就会调整学习参数。

最后是测试优化环节。用全新的、未训练过的数据检验AI，比如突然给它一张熊猫
照片。如果AI 误判，就要返回调整模型结构，可能需要更换更复杂的神经网络。这个
过程往往要重复几十次，直到准确率达到实用标准（如95%以上），才能部署成手机APP、
智能硬件等应用。

目前全球超过70%的AI 应用都遵循这个流程，从自动驾驶到作业批改系统都是如
此。下次使用拍照识花功能时，你可以想象背后经历了：采集200 万张植物图库→删除
重复图片→训练模型区分花瓣形状→反复测试确保准确率→最终变成你手机里的神奇
功能。

知识卡片：模型训练中的过拟合现象

在机器学习中，“过拟合”就像一个学生只为了应付考试死记硬背答案，却不会灵活运用
知识。这就像考试背答案：如果学生把练习题的答案背得一字不差，考试碰到原题能得满
分，但题目稍微改个形式（比如换数字或场景），他就不会做了。这就像模型在训练数据（练
习题）上表现完美，但遇到新数据（变形题）就“露馅”了。

过拟合原因可能是模型太复杂（比如背了太多细节），或者训练数据太少（只见过少量
题目），导致它“学歪了”。想要解决过拟合问题，需要让模型更“灵活”一点，比如简化它的
结构，或者用更多样化的题目（数据）训练它，避免它只会“死记硬背”。

简单说，过拟合就是“学得太死板，不会举一反三”！

4. 轻量级代码实践

让我们通过一个简单案例感受机器学习的力量。以下代码使用决策树算法预测学习
时间与考试成绩的关系：

from sklearn.tree import DecisionTreeClassifier
# 创建数据集：学习时间vs 考试成绩

X = [[0.5], [1],  [2],  [4], [6], [8]] # 学习时间（小时）
y = [0, 0, 0, 0, 1, 1]     # 是否及格（0/1）

# 训练决策树
clf = DecisionTreeClassifier()
clf.fit(X, y)

# 预测学习7小时的结果
print(clf.predict([[7]])) # 输出：1（及格）

运行这段代码后，尝试修改输入值观察变化。例如输入3 小时，模型可能预测不及
