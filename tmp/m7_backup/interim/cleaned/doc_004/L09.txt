1、计算机视觉中的手势识别：手势识别像教AI学“手语”。通过摄像头捕捉手部动作（如
比心、挥手），AI能理解你的手势指令，用来控制游戏、智能家居，甚至翻译手语。
2、手势识别原理：
关键点检测：AI 识别手势需要先给手画“骨骼图”——AI 先找到手掌、指尖等21
个关键点（如用MediaPipe 标出手指关节），再根据这些点的位置变化判断手势（
如张开五指=‘停止’，握拳=‘确定’）。
特征工程：AI分析手的形状（如手掌大小）、运动轨迹（如从左到右挥动）等特征，
再用数学公式总结规律（比如‘比心’手势的指尖距离公式），最终识别出你的动作。
3、OpenCV库实践：图像采集
OpenCV库能实时调用摄像头，把你的手势变成一帧帧图片，再通过“灰度化”、“边
缘检测”等处理（类似给照片加滤镜），帮AI更清晰地‘看’手势。

二、知识衔接

1. 关键点检测

我们要让计算机识别手势，首先得让计算机知道手的形状和位置。这里就要用到关
键点检测技术。MediaPipe 手部关键点模型通过深度学习定位手掌的解剖学特征点。模
型的关键点分布在手的不同部位，就像给手上的重要位置做了标记一样。每个关键点包
含(x,y,z)三维坐标，通过这些坐标，我们就能知道手的姿态。

9. 要实现手势识别，我们需要获取实时的图像数据，这就需要调用摄像头。在Python
中，我们可以使用OpenCV 库来调用摄像头。下面是一个简单的示例代码：
# MediaPipe手部检测示例
import cv2
import mediapipe as mp

mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=1)

cap = cv2.VideoCapture(0)
while cap.isOpened():
success, image = cap.read()
if not success: break

results = hands.process(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))
if results.multi_hand_landmarks:
for hand_landmarks in results.multi_hand_landmarks:
# 获取食指指尖坐标（8号点）
index_finger = hand_landmarks.landmark[8]
print(f"X:{index_finger.x}, Y:{index_finger.y}")

2. 手势特征工程

我们可以获取食指指尖关键点和拇指指尖关键点的坐标，然后计算它们之间的距离。这
个距离就可以作为一个手势特征，当我们改变手势时，这个距离也会发生变化。大家想一想，
除了食指和拇指的距离，还可以用哪些关键点之间的距离或角度来表示手势特征呢？
运行下面的代码，尝试通过关键点间距计算手势特征：

def get_distance(landmarks, point1, point2):
# 计算两个关键点的欧氏距离
dx = landmarks[point1].x - landmarks[point2].x
dy = landmarks[point1].y - landmarks[point2].y
return (dx**2 + dy**2)**0.5

# 判断"比心"手势示例
thumb_tip = hand_landmarks.landmark[4]
