1、计算机视觉技术（CV）：AI是如何看见的？
AI把图片拆成无数小格子（像素点），每个格子记录颜色深浅（0=黑，255=白），像
用显微镜看拼图。比如猫的图片在AI眼里是红、绿、蓝三张‘数字网格’叠加而成。
2、CNN卷积运算原理：像用智能滤镜扫描图片，CNN用‘小窗口’（卷积核）滑动检测
特征，比如第一层找边缘（横线、竖线），深层组合边缘成眼睛、爪子，最终认出‘这是
猫’。类似用放大镜逐块观察拼图，总结整体图案。
3、图像边缘检测：AI用数学‘筛子’（如Sobel算子）找到颜色变化大的地方，确定为图
像边缘，像用铅笔勾勒轮廓。比如用手机‘描边’滤镜把风景照变成简笔画，原理和自动
驾驶识别车道线一样。

像素的秘密想象用放大镜观察照片，
会发现图像由无数小方块构成，这些
就是像素。每个像素本质上是三个数
值的组合：红色(R)、绿色(G)、蓝色(B)
通道的强度值（0-255）。例如纯白
色对应(255,255,255)，纯黑色对应
(0,0,0)。

数字乐高积木计算机将图像存储为
三维矩阵（配图建议：用Excel 表格
模拟灰度图像）。例如一张100x100
像素的彩色照片，实际是100 行×100
列×3 层的数字矩阵。第一层是红色
通道强度，第二层是绿色通道，第三
层是蓝色通道。灰度图像则是单层矩
阵，数值范围0（黑）到255（白）。

import cv2

def edge_detection(image_path):
# 读取图片
img = cv2.imread(image_path)
if img is None:
print("图像无法加载，请检查路径")
return

# 转换为灰度图像（因为彩色图像包含三个通道，而边缘检测主要是在灰度图像上
效果更好）
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 使用高斯模糊来减少噪声和细节，这样可以得到更清晰的边缘
blurred = cv2.GaussianBlur(gray, (5, 5), 0)

# 使用Canny算法进行边缘检测，该算法通过计算梯度来检测图像中的强边缘
edges = cv2.Canny(blurred, 50, 150)

# 显示原图和边缘检测后的结果
cv2.imshow("Original Image", img)
cv2.imshow("Edges Detected", edges)

# 等待按键然后关闭所有窗口（可以按任意键关闭窗口）
cv2.waitKey(0)
cv2.destroyAllWindows()

# 替换成你的图像路径
image_path = 'path/to/your/image.jpg'
edge_detection(image_path)

代码讲解

1. 读取图像：使用cv2.imread() 函数读取图像文件。如果路径错误，程序会提示“图
像无法加载，请检查路径”。
2. 转换为灰度图像：通过cv2.cvtColor() 将彩色图像（BGR 格式）转换为灰度图像。
灰度图像是单通道的，更适合用于简单的边缘检测操作。
3. 高斯模糊：使用cv2.GaussianBlur() 对灰度图像进行高斯模糊处理。模糊的目的是
减少图像中的噪声和细节，使得后续的边缘检测能够更精准地识别显著的边缘。
cv2.GaussianBlur() 的参数(5,5) 表示高斯核的大小为5×5，0 表示标准差由系统自
动计算。
4.  Canny 边缘检测：使用cv2.Canny() 函数进行边缘检测。cv2.Canny() 是一种基于
多阶段算法的边缘检测方法，其主要步骤包括：

⟦P43⟧
o 用高斯模糊降噪。
o 计算图像中每个像素点的梯度强度和方向。
o 应用非极大值抑制来去除边缘伪响应。
o 使用双阈值（这里为50 和150）检测和连接边缘。最后得到的edges 是
二值图像，其中边缘像素被标记为白色。
5. 显示图像：使用cv2.imshow() 显示原图和边缘检测的结果。cv2.waitKey(0) 表示程
序会等待用户按下任意键，cv2.destroyAllWindows() 会关闭所有图像窗口。

延伸思考：数据质量对模型的影响

测试上面的代码时，如果使用模糊的照片，会发现边缘检测效果变差。这说明高精
度的图像数据对于计算机视觉任务至关重要。想象一下，我们在搭积木时，如果积木的
形状和大小不规则或者破损，那就很难搭建出理想的模型。同样，在计算机视觉中，数
据的质量决定了模型能否有效地识别和处理图像。因此，在实际应用中，我们通常需要
对图像进行预处理，比如调整尺寸、裁剪、去噪、校正颜色等，以提高数据质量，从而
提升模型的性能。
