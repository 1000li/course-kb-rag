import datetime

item = input("请输入垃圾名称（如‘电池’）：")
now = datetime.datetime.now().strftime("%Y-%m-%d %H:%M")

if "电池" in item:

elif "纸" in item or "塑料" in item:

知识延伸：为什么用Python 学AI？

1、语法简单，专注创意
- 用Python 写代码就像搭积木，比如实现AI 画爱心只需5 行代码，其他语言可能需要
50 行。
- 语法接近自然语言，新手不用纠结复杂规则，直接进入AI 核心逻辑。
2、强大的“工具箱”支持
- Python 有超多AI 专用库（工具包），比如：
- TensorFlow/PyTorch：训练AI 模型像拼乐高一样简单。
- OpenCV：轻松实现人脸识别、图像处理。
- SpeechRecognition：3 行代码让AI 听懂你的声音。
3、全球开发者“朋友圈”
- 遇到问题？全球超1000 万Python 开发者为你解答！比如搜索“Python 垃圾分类”，立
刻找到现成代码模板。
4、从课堂到未来的应用
- NASA 用Python 分析火星照片，抖音用它推荐视频，游戏《原神》也离不开Python。
- 掌握Python，就像拿到打开AI 世界的钥匙，能快速实现创意项目。

Python 是AI 学习的“超能力加速器”，语法简单、工具丰富、应用广泛，让你专注
创新，快速实现酷炫的AI 项目！
